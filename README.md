# VIA AI - Mobile Application (Frontend)

## 📌 Giới thiệu
Đây là mã nguồn Frontend cho ứng dụng **VIA AI** - Trợ lý ảo Chatbot thông minh. Ứng dụng được xây dựng bằng **React Native** (Expo Framework) và sử dụng kiến trúc điều hướng tùy chỉnh (Custom State-based Navigation) để tối ưu hóa hiệu năng và độ ổn định.

## 🛠 Công nghệ sử dụng
- **Core**: React Native (Expo SDK 52+)
- **Ngôn ngữ**: TypeScript
- **UI Architecture**: Component-based
- **Navigation**: Custom Context-based Navigation (Không sử dụng thư viện điều hướng bên thứ 3)
- **API Integration Point**: Mocked functions (cần Backend đấu nối)

### 1. Root (`/`)
*   **`App.tsx`**: **[QUAN TRỌNG NHẤT]**
    *   Đây là "trái tim" của ứng dụng.

    *   **Logic Auth Mock**: Hàm `login()` hiện tại đang mock (giả lập) độ trễ 1s và trả về user giả. Backend cần thay thế logic này bằng API call thực tế.

### 2. Màn hình (`src/screens/`)
Các màn hình giao diện chính của ứng dụng:

*   **`LoginScreen.tsx`**:

    *   Hiện tại đang gọi hàm `login()` từ `NavigationContext` (trong `App.tsx`).

*   **`ChatScreen.tsx`**:
    *   Giao diện chat chính với AI.
    *   **Backend Todo**:
        *   Cần đấu nối API `POST /chat/send` vào hàm `handleSend`.
        *   Cần xử lý Streaming Response (nếu có) hoặc Polling để nhận câu trả lời từ bot.
    *   Dữ liệu tin nhắn đang được lưu trong Local State (`messages`).

*   **`HistoryScreen.tsx`**:
    *   Hiển thị danh sách lịch sử các cuộc trò chuyện cũ.
    *   **Backend Todo**:
        *   Cần đấu nối API `GET /chat/history` để lấy danh sách.
        *   Cần đấu nối API `DELETE /chat/history/:id` vào hàm `handleDelete`.

*   **`SettingsScreen.tsx`**:
    *   Màn hình cài đặt (Dark mode, Logout, Thông tin).
    *   Chức năng Logout gọi hàm `logout()` từ `NavigationContext`.

## 🔌 Hướng dẫn Tích hợp API (Cho Backend Dev)

Hiện tại, toàn bộ logic API đang được giả lập (Mock). Để tích hợp Backend thực tế, vui lòng chỉnh sửa các vị trí sau:

### 1. Authentication (Đăng nhập)
*   **File**: `App.tsx`
*   **Hàm**: `login(email, password)`
*   **Yêu cầu**: Thay thế `setTimeout` bằng `fetch` hoặc `axios` đến Endpoint Login. Lưu Token vào `AsyncStorage` hoặc SecureStore.

### 2. Chat (Gửi tin nhắn)
*   **File**: `src/screens/ChatScreen.tsx`
*   **Hàm**: `handleSend(text)`
*   **Yêu cầu**: Gọi API gửi tin nhắn. Xử lý loading state khi chờ phản hồi.

### 3. Lịch sử Chat
*   **File**: `src/screens/HistoryScreen.tsx`
*   **Hàm**: `HistoryScreen` (useEffect)
*   **Yêu cầu**: Fetch dữ liệu lịch sử ngay khi màn hình được mount.
